# Heitor Delfino — Portfolio

**Portfolio pessoal** de desenvolvedor em transição da gastronomia para a tecnologia.

🌐 **Live**: [portfolio-heitor-rafael.vercel.app](https://portfolio-heitor-rafael.vercel.app)

---

## Stack

- **React 18** + **TypeScript** + **Vite**
- **react-router-dom v7** — rotas para páginas individuais de cada projeto
- **Tailwind CSS** — estilos utilitários
- **Vercel** — deploy automático via GitHub

## Design

Editorial dark — tipografia Playfair Display (serif) + JetBrains Mono, paleta ink/paper/red.
